# Grocery Bill Tracker

A simple React app for tracking grocery prices as you shop. Add an item's price and quantity, edit or delete entries, and see a running total — all in a high-contrast grayscale UI.

## Features

- Add items with price and quantity
- Running total, always visible
- Edit or delete any entry
- Clear the whole list to start over

## Getting started

```bash
npm install
npm run dev
```
